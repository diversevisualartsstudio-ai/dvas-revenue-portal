# DVAS Revenue Portal

Enterprise AI Revenue & Security Portal for Diverse Visual Arts Studio LLC.

## Overview
This repository contains a lightweight static dashboard for monitoring revenue performance, pipeline health, and compliance/security posture for a modern AI-first business.

## Run locally
You can open the app directly in a browser, or serve it locally with a small web server.

### Option 1: Open directly
- Open `index.html` in your browser.

### Option 2: Serve locally
From the repository root:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files
- `index.html` — the portal UI and embedded styles/scripts
- `README.md` — project overview and run instructions

## Notes
This project is intentionally lightweight and requires no build step, package installation, or external dependencies.
